# @splitsecure/proto

Generated TypeScript bindings for the SplitSecure protobuf APIs, built with
[protobuf-es](https://github.com/bufbuild/protobuf-es) v2.

```bash
npm install @splitsecure/proto @bufbuild/protobuf
```

One subpath per generated file:

```ts
import { TeamBaseInfoSchema } from "@splitsecure/proto/splitsecure/teamresource/v1/team_base_info_pb";
```

`@bufbuild/protobuf` is a peer dependency, so one copy is shared with whatever
else in the consumer uses it.

This package is generated from the protobuf definitions in the
[repository](https://github.com/splitsecure/apis). Do not edit it by hand.
